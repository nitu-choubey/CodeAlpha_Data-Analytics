## Task 3: Data Visualization

###  Overview
Transformed raw data into insightful visual formats and charts using **Python**, **Matplotlib**, and **Seaborn** to uncover underlying patterns, trends, and relationships for data-driven decision-making.

###  Tools & Libraries Used
* **Python**
* **Pandas & NumPy** (Data Handling)
* **Matplotlib & Seaborn** (Data Visualization)

###  Key Visualizations Generated
1. **Distribution of Total Bill Amounts:** Histogram with KDE plot to understand the distribution pattern of restaurant bills.
2. **Total Bill vs Tip Amount:** Scatter plot analyzed across days of the week and timings using color-coded hues.
3. **Average Tip by Day:** Bar plot representing tip variations across different days of the week.
